How to Update Garmin Forerunner 165
===================================

There are several ways to install the latest software on your device.

Method 1: Update Using Wi-Fi
----------------------------

If your watch is connected to a trusted Wi-Fi network:

1. Connect the watch to a charger.
2. Ensure Wi-Fi is enabled.
3. Leave the device connected.
4. The watch automatically checks for available updates.
5. Follow the on-screen instructions if an update is available.

Method 2: Update Using Garmin Connect
=====================================

When paired with a compatible smartphone:

- Open the Garmin Connect app.
- Synchronize your watch.
- Wait while the app checks for available software.
- Install updates if prompted.

Automatic synchronization makes this the easiest option for many users.

Method 3: Update with Garmin Express
====================================

Garmin Express provides another reliable update method.

Steps include:

1. Install Garmin Express on your computer.
2. Connect the watch using the supplied USB cable.
3. Open Garmin Express.
4. Add your device if necessary.
5. Check for software updates.
6. Install available updates.
7. Disconnect the watch only after installation is complete.

Preparing Your Watch Before Updating
====================================

Before starting an update:

- Charge the battery above 50%.

- Sync your recent activities.
- Keep the device connected during installation.
- Avoid interrupting the update process.

These simple steps reduce the risk of installation issues.

How to Check Your Current Software Version
==========================================

To view the installed version:

1. Open **Settings**.
2. Select **System**.
3. Choose **About**.
4. Review the current software version.

This information helps determine whether your watch is running the latest release.

Common Garmin Forerunner 165 Update Problems
============================================

Occasionally, users may experience update issues.

Update Not Appearing
--------------------

Possible causes include:

- No new software has been released.
- Synchronization has not completed.
- Poor internet connectivity.

Slow Installation
-----------------

Large software packages or slow internet speeds may increase installation time.

Bluetooth Connection Issues
---------------------------

Ensure Bluetooth remains enabled on both the smartphone and watch throughout the update process.

Battery Too Low
---------------

Some updates require sufficient battery power before installation begins.

Watch Freezes During Update
---------------------------

If the update appears stalled:

- Wait several minutes.
- Restart the watch if necessary.
- Retry the installation after reconnecting.
